# 示例：2分钟长视频 — 先做最小的一步（A+B 路线扩展版）

- 主题：19岁大二，一边上课一边做跨境建材外贸，记录真实创业过程
- 受众：19-22岁想折腾但不敢开始的大学生
- 目标时长：约120秒，语速约240字/分钟
- 下面每行是一个节拍，格式 [开始-结束] 台词，供 split_storyboard.py 解析

[00:00-00:05] 晚上十一点，客户问我，瓷砖胶多少钱一袋，我盯着屏幕三分钟，没敢回。
[00:05-00:30] 不是我不想回，是我成本还没对齐，怕说错一个数，就丢了这个客户。那一刻我才明白，我不是缺准备，我是怕丢脸。我以前总想一次做到完美，结果就是什么都不敢做，越等越不敢开始。宿舍里没人教我这些，都是我一边上课，一边在客户消息里学会的。
[00:30-01:15] 后来我换了一个办法，把不敢做的事，拆成最小的一步。先不报价，先回一句话，我去核对一下，明天给你准确价格。第二天，我问了工厂，拿到了真实成本。第三天，我才报了价。价格报出去之后，客户没有走，反而多问了我一句，你们还有别的产品吗。这件事让我明白一个道理，客户要的不是完美答案，是一个真实的回应。我现在做事就三条，第一，先问工厂要真实成本，不自己编一个数。第二，先给一个真实的回应，不装懂。第三，能发的先发，拿到反馈再改一版。把大任务拆小，把第一步做小，先发一个六十分的版本，再按反馈改一版，比在原地等一百分有用得多。
[01:15-01:45] 所以如果你现在也卡住了，别问自己准备好了没有，先问自己，今天能做的最小一步是什么。能发一句消息，就先发一句。能问一个问题，就先问一个。创业不是等准备好，是先把最小的一步做出来。
[01:45-02:00] 你现在最不敢做的那一步是什么，评论区告诉我，我下条视频就讲你那一步怎么拆。
